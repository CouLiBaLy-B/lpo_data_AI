Modèle (extraction d'intention)

Le modèle ne voit jamais les données : il choisit seulement le type de vue et les filtres. Les chiffres viennent des outils MCP.

Serveur MCP

Le transport HTTP vise un serveur déjà lancé ; le transport local exécute une commande sur la machine du serveur web.

Sécurité : les clés ne sont jamais renvoyées par le serveur. En production, préférez le transport HTTP et LPO_WEB_SETTINGS=url-only ou off (configuration figée par l'environnement).

Une question, une interface

Les réponses sont composées uniquement de composants du catalogue LPO (LineChart, BarChart, MapChart, KpiCard, DataTable, Notice, SelectField). Le serveur n'envoie ni HTML, ni CSS, ni JavaScript.

Les filtres de la surface renvoient une action à l'agent : il rappelle les outils MCP, puis n'envoie que les données. La structure n'est pas recréée.
