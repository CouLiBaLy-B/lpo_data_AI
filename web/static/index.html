Une question, une interface

Les réponses sont composées uniquement de composants du catalogue LPO (LineChart, BarChart, MapChart, KpiCard, DataTable, Notice, SelectField). Le serveur n'envoie ni HTML, ni CSS, ni JavaScript.

Les filtres de la surface renvoient une action à l'agent : il rappelle les outils MCP, puis n'envoie que les données. La structure n'est pas recréée.
