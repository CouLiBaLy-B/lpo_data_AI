# Fond de carte

`departements.geojson` dérive de
[gregoiredavid/france-geojson](https://github.com/gregoiredavid/france-geojson)
(`departements-version-simplifiee.geojson`), lui-même issu d'IGN / Admin Express
COG 2018 et INSEE COG 2018, sous **Licence Ouverte / Open Licence 2.0** (Etalab).

Modifications : métropole uniquement, coordonnées arrondies à 0,01° (précision
d'affichage), anneaux dégénérés supprimés, format compact. Ce fond sert
uniquement de repère visuel : les points d'observation proviennent exclusivement
du serveur MCP.
